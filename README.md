# Emergency Green Corridor Management System 🚑

## Project Overview
The Emergency Green Corridor Management System is a Flask-based web application that helps ambulances reach hospitals quickly by creating a green corridor.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Modules
- Home Page
- About Page
- Emergency Request Form
- Admin Login
- Admin Dashboard
- Police Dashboard
- Hospital Dashboard
- Traffic Dashboard
- Notifications

## Features
- Submit emergency requests
- Admin approval/rejection
- Export CSV
- Search requests
- Live status tracking
